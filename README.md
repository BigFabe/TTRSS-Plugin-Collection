# What this is 

This is my small collection of plugins I vibecoded 

# What is included?
*feedly-patched*
At the time being, the [feedly theme](https://github.com/levito/tt-rss-feedly-theme/tree/dist) isn't working. This version does.

*scrolloff*
I use keybindings for navigation, but I'm always a bit annoyed not seeing what is coming. This plugin adds a small offset, so there are always a self defined number of articles between you and the bottom. No more surprises.

*share_to_karakeep*
Does what it says. A little plugin for sharing articles to Karakeep via a simple click.
